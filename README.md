# Rough Cuts Website

Static site hosted on GitHub Pages from the `docs/` folder on the `main` branch.
Only files inside `docs/` are published to roughcutsjam.com; everything else (notes, README, CLAUDE.md) stays on GitHub only.

## Working on it

1. `git pull` before you start.
2. Edit files, open `docs/index.html` in a browser to check.
3. `git add -A`, `git commit -m "what you changed"`, `git push`.

Pushes to `main` go live in about a minute.
